# ProductShala

**AI-powered sentiment analysis for smarter product insights**

---

## 📌 Overview

**ProductShala** is a full-stack application that performs sentiment analysis on product reviews. It uses Natural Language Processing (NLP) and machine learning techniques to classify reviews as **positive or negative**, helping users and businesses quickly understand customer feedback.

The project is divided into:

* **Backend**: Handles data processing, model prediction, and API logic
* **Frontend**: Provides a user interface to input reviews and view results

---

## 🚀 Features

* Sentiment classification (Positive / Negative)
* Text preprocessing and prediction pipeline
* REST API-based backend
* Interactive frontend interface
* Modular and scalable project structure

## ⚙️ Installation & Setup

### 1. Clone the Repository

```
git clone https://github.com/your-username/ProductShala.git
cd ProductShala
```

---

### 2. Setup Backend

```
cd backend
pip install -r requirements.txt
python app.py
```

---

### 3. Setup Frontend

```
cd frontend
npm install
npm run dev
```

---

## ▶️ Usage

1. Start the backend server
2. Run the frontend application
3. Enter a product review in the UI
4. View predicted sentiment (Positive / Negative)
